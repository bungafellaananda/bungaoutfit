# BFÉ Fashion Store

Modern, minimal, responsive fashion store untuk GitHub Pages.

## File
- index.html
- style.css
- script.js
- products.json
- IMAGE-SOURCES.md

## Fitur
- Responsive + fluid layout
- Product data JSON
- Search
- Filter kategori
- Sorting
- Wishlist (LocalStorage)
- Shopping cart + quantity (LocalStorage)
- Product detail modal
- Lookbook
- ID/EN button preview
- Newsletter
- Back to top
- Modern maroon & navy UI

## GitHub Pages
1. Extract ZIP.
2. Upload semua file ke repository GitHub.
3. Pastikan `index.html` berada di root.
4. Settings → Pages → Deploy from a branch.
5. Branch `main` dan folder `/(root)`.
6. Save.

## Catatan gambar
Gambar menggunakan tautan foto online dari Unsplash yang ditemukan melalui pencarian web. Internet diperlukan agar gambar tampil. Jangan menghapus koneksi gambar dari products.json.
